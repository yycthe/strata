# **App Name**: StrataPulse Pro

## Core Features:

- Intelligent Email Ingestion: Automatically connect to Gmail via IMAP, sync recent emails, perform de-duplication, extract and clean content, and identify strata plan codes, storing qualified notices in a SQLite database.
- AI-Powered Notice Summarization & Audience Detection: Utilize a generative AI tool (Gemini API) to automatically summarize ingested email content into structured insights (what, when, impact, action) and intelligently determine the appropriate distribution audience with confidence and evidence.
- Owner & Property Data Management: Allow bulk import of owner and property data via CSV, maintaining precise associations between owners, their properties, and strata plan codes for highly targeted notice dispatch.
- Workflow Dashboard & Queues: Provide a central dashboard to monitor Gmail sync status, manage a queue of pending notices, review dispatched items in history, and display system logs, complete with search and bulk action capabilities.
- Review & Targeted Dispatch Module: Enable users to meticulously review AI-generated summaries and audience recommendations, select specific target owners based on property associations, and efficiently dispatch notices, with comprehensive history tracking.

## Style Guidelines:

- Primary color: A deep, professional blue (#2461CD) to convey reliability and authority in a modern context. It contrasts effectively with lighter UI elements.
- Background color: A very light, subtle blue-gray (#F2F6F9) that promotes readability and offers a clean, calm canvas for detailed information display.
- Accent color: A vibrant yet refined purple (#692EF7) to highlight key actions, statuses, and interactive elements, adding a modern and engaging visual cue.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly technical feel, suitable for titles and emphasized text, reinforcing the 'Pro' aspect of the application.
- Body text font: 'Inter' (sans-serif) for its high readability and neutral, objective appearance, ideal for extensive text content like email summaries, data tables, and forms.
- Employ a consistent set of clean, modern line icons to visually represent actions and categories, ensuring clarity and intuitive navigation within the workflow.
- Adhere to a clear, two-column layout with a fixed left sidebar for navigation and a spacious right main content area, optimizing for workflow efficiency and data presentation on desktop screens.
- Incorporate subtle, performant UI animations for transitions between views and upon data loading or submission, providing gentle feedback and enhancing the sense of a responsive, polished application.
